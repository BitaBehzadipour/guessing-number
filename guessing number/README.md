# 🎯 Guess My Number Game

A fun number guessing game built with **HTML**, **CSS**, and **Vanilla JavaScript**.

The goal is to guess the secret number between **1 and 20** with the highest possible score.

---

## ✨ Features

- 🎲 Random number generation
- 🎮 User guesses numbers between 1 and 20
- 📉 Score decreases after every wrong guess
- 🏆 High score tracking
- 📢 Helpful hints:
  - Too High
  - Too Low
  - Correct Number
- 🎉 Win animation and background color change
- 🔄 Restart the game with the **Again!** button

## 🚀 How to Run

1. Clone the repository

```bash
git clone https://github.com/YourUsername/guess-my-number.git
```

2. Open the project folder.

3. Open `index.html` in your browser or use **Live Server** in VS Code.

---

## 🎮 How to Play

1. Enter a number between **1 and 20**.
2. Click the **Click** button.
3. If your guess is:
   - 📈 Too high → Try a smaller number.
   - 📉 Too low → Try a larger number.
   - ✅ Correct → You win!
4. Your score decreases after each incorrect guess.
5. Press **Again!** to start a new game.
